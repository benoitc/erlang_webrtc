# ETSI SCTP conformance tests

The packetdrill scripts of the ETSI TS 102 369 test purposes, from https://github.com/nplab/ETSI-SCTP-Conformance-Testsuite (commit c6144e8), under the license in `LICENSE.md`. `webrtc_sctp_etsi_tests` runs them through `webrtc_sctp_drill`, an interpreter for the subset of packetdrill they use, against the sans-IO association.
